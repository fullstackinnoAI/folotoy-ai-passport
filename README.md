# FoloToy AI Passport plays

This repository collects plays for the FoloToy AI Passport. Each play has its own folder under [`apps/`](apps/mbti/README.md). Board support shared by every play stays in `components/bsp`.

Keep later plays as folders in this repository. Do not give each play its own branch, and do not create a separate repository per play. A folder keeps the shared board code in one place and lets the repository page list every play.

## Plays

| Play | Folder |
| --- | --- |
| Personality quiz | [`apps/mbti`](apps/mbti/README.md) |

The personality quiz is the firmware built from the repository root. Its screens and scoring live in `apps/mbti/`.
