# Personality quiz

An offline quiz. The player enters an age and a gender, answers sixteen short questions, then sees a four-letter type, a one-line comment, and a matching card.

Build it from the repository root with the usual firmware command. These sources are compiled through `main/CMakeLists.txt`. Cards and fonts stay in `assets/`.
