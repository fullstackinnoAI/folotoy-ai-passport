# FoloToy AI Passport 玩法

这个仓库收录 FoloToy AI Passport 上的玩法。每个玩法放在 [`apps/`](apps/mbti/README.zh_CN.md) 下的独立文件夹里。所有玩法共用的板级代码留在 `components/bsp`。

以后的玩法继续用文件夹放进这个仓库。不要为每个玩法开一条分支，也不要每个玩法单独建一个仓库。文件夹能共用板级代码，仓库首页也能同时看到全部玩法。
